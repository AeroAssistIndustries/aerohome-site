# AeroHome website

Live at **https://aeroassistindustries.github.io/aerohome-site/** (GitHub Pages, published from `main`).

| File | What it is |
|---|---|
| `index.html` | Home page |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms of Use |
| `404.html` | Page-not-found screen |
| `og.jpg` | Preview image shown when a link to the site is shared |

Each page is one self-contained file: styles, scripts and images are built in, so there is nothing else to upload.
To update the site, replace these files with a new build and commit to `main`; GitHub Pages republishes within a minute or two.

Before launch: have counsel review the Privacy Policy and Terms of Use, then remove the "Template notice" box from each.
